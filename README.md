# Personal Information Manager

## 📌 Project Description

This is my first Python project!  
The Personal Information Manager is a beginner-friendly Python application that stores and displays personal information using variables, user input, string formatting, and validation.

The program demonstrates fundamental Python concepts such as:
- Variables and data types
- Input and output operations
- String formatting with f-strings
- Input validation
- Basic calculations

---

# 🎯 Project Objectives

- Learn Python basics through a real project
- Practice using variables and user input
- Understand formatted output using f-strings
- Implement simple input validation
- Improve code readability with comments

---

# ✨ Features

- Stores static information:
  - Name
  - Age
  - City
  - Hobby

- Gets dynamic user input:
  - Favorite food
  - Favorite color

- Displays all information in a formatted structure
- Calculates age in months
- Includes welcome and goodbye messages
- Handles empty input validation
